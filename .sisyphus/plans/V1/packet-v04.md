# v04 — Вертикальное доказательство S-цепочки

## Цель
Приостановка, человеческая валидация, возобновление и опровержение проходятся по шагам с evidence и отличимым статусом, потому что цепочка, где шаг можно пропустить, доказывает только собственную пропускную способность.

## Обоснование (измерено)
- `crates/stellwerk-core/src/contract.rs:185` — здесь объявлены статусы, которые цепочка обязана различать на каждом шаге.
- `crates/stellwerk-task/src/runner.rs:272` — здесь приостановка уже связана с отсутствием ответа, и цепочка начинается из этого состояния.

## Шаг 1 — падающий тест
`crates/stellwerk-cli/tests/vertical_v4.rs`, тест `suspension_validation_refutation_chain`: требует, чтобы каждый шаг оставлял evidence и отличимый статус; до связывания шагов цепочка доходит до конца без записи о валидации, и тест падает на пропущенном шаге.

## Приёмка
cargo test -p stellwerk-cli --test vertical_v4
Ожидается PASS.

## Запрещено
- нельзя проходить шаг без записи.
- запрещено сливать статусы шагов в один.
- нельзя считать тишину валидацией.
