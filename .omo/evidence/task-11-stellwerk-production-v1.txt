===== IMPLEMENTATION NOTES =====
- `read`/`edit`/`write` are registered with `pi.registerTool` + TypeBox schemas.
- `execute` sends `{kind:"tool_call", tool, parent_tool_call_id:null, path,
  argument, content_digest?}` to `gate.sock`; effects apply only after
  `allow`/`authorized`, and every other answer becomes an isError result.
- `content_digest` is SHA-256 over the exact `JSON.stringify(params)` bytes
  carried as `argument`, matching `RequestedCall::new`.
- `pi.on("tool_call")` remains as the pre-effect belt for builtin tools
  (`bash` etc.); extension tools are gated inside `execute` so the gate sees
  the full typed call and no double frame is sent.
- `pi_transport_args` filters `read`/`edit`/`write` from `--tools`; when no
  builtin remains it passes `--no-builtin-tools`, leaving the extension tools
  active by default. `bash` remains explicitly allowed for the existing
  gated builtin path.
- Forbidden patterns absent: no new deps, no `#[allow]`, no `#[ignore]`,
  no `unwrap()` in new production code, no `cargo fmt --all`, no `git add -A`.
