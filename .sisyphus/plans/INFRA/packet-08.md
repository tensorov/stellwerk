## Контекст

Три ручных аудита подряд дали ложные результаты, и все три — из одного класса: инструмент
дал вывод, вывод принят за факт, факт опровергнут прямой проверкой. `cut -c1:44` обрезал
`workspace_policy` до `workspace`, на чём была построена ложная находка про M1; `awk`
прочитал только первую строку `test result` из нескольких бинарников; переменная с `\n`
попала под glob zsh и выдала «нет бинарника» для существующего `ledger_encoding`.

Здесь закрывается только **разбор**. Исполнение — отдельный пакет, потому что смешивать
разбор с исполнением означало бы невозможность проверить первое, не запустив второе.

## Что сделать

1. `scripts/packet_replay.py` — Python stdlib, без новых зависимостей. Точка входа принимает
   **режим из закрытого enum**, а не путь и не команду от вызывающего: `inventory`.
   Произвольный путь означал бы, что вызывающий выбирает, что именно проверяется, а
   аттестуемость требует, чтобы список был в коде.
2. Обход: `glob` по `.sisyphus/plans/*/packet-*.md`. Явно пропустить любой путь, содержащий
   `_archive`. `.omo/plans/` **не обходить вообще** — это зеркало, а не источник истины, и
   чтение зеркала однажды уже роняло раздачу.
3. Поле `test:` искать **по структуре**, а не по вхождению слова: строка, начинающаяся с
   `test:` в начале строки (после необязательных пробелов), вне code block. Слово `test` в
   прозе и внутри ``` не является полем — это и есть проверка на ложное срабатывание.
4. Извлекать: `packet_id`, `milestone`, `goal`, `depends_on`, команда, признак
   RED/GREEN **если он присутствует явно**, путь-источник. RED/GREEN берётся из начала
   `goal`, а не угадывается по наличию слова.
5. Команду читать **целиком, без обрезки**. Никаких `cut`, никакого shell word-splitting:
   значение берётся из строки целиком и сохраняется как есть, что самотёстом и
   проверяется на `workspace_policy`.
6. Статусы разбора: `PARSED`, `NO_COMMAND`, `PARSE_ERROR`. Статус на пакет, не на файл.
7. Вывод — inventory в stdout. Ничего не запускать. Числа печатать из посчитанного, а не
   подставлять: ориентиры брифа «около 96 / 89 / 7» суть гипотеза, и печатать их значило бы
   подделать результат, который инструмент как раз и должен получить.

## Self-tests, обязательные

1. Однострочное `test: cargo test …` разбирается.
2. Команда, обёрнутая в backticks, разбирается.
3. Слово `test` в прозе и в code block полем **не** считается.
4. Пакет без `test:` → `NO_COMMAND`.
5. `_archive/` не попадает в обход.
6. `.omo/plans/` не попадает в обход.
7. `workspace_policy` сохраняется полностью, до последнего символа.
8. Ни `cut`, ни shell word-splitting, ни zsh glob не используются — это проверяется чтением
   кода инструмента в тесте, а не декларацией.
