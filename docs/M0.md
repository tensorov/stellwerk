# M0 — nexus-registry

СКОУП: crate `nexus-registry`, бинарь `nexus`, команды `module add|measure|audit|update`.

- add     — добавить модуль в modules.toml из git/npm/cargo источника, ничего не собирать.
- measure — посчитать байты/символы JSON-схем тулов MCP-сервера, применить
            [registry.calibration], записать context_cost_tokens в modules.lock.
- audit   — поднять MCP-сервер (kind="mcp" ТОЛЬКО), tools/list, по одному tools/call
            на каждый заявленный тул, сверить с manifest.
- update  — fetch -> build -> smoke(audit) -> measure -> `gh pr create`. НИКОГДА не merge.
            Без `gh` — записать патч в .nexus/pending/ и остановиться.
