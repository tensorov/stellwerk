18a даёт измерение, 18b кладёт его в память Run. Поле измеренное, а не вычисленное
по умолчанию: если замера не было, это отдельное состояние, а не ноль.

1. Поле score в памяти Run заполняется только из outcomes.json, с путём к файлу и

2. N/A записывается как N/A. Отсутствие замера и 0% различимы.
3. Запись появляется только для критических крейтов.

чтобы некритический крейт записи не создавал.
