**Строка xl (решение владельца 2026-10-05).** Отдельная запись, не замена 46k-строки:
`qwen3.6-unlim-noreason` сохраняется с теми же именем и числами, потому что на ней
измерены все числа плана mutation gate и конфиги A–E. xl не вытесняет и не переименовывает
предшественника.

Лимит **138 336 — общий**: вход, выход и схемы инструментов в сумме. Это не «вход
138 336». Остаток на выход вычитается из доступного входа.

Значения xl **не калиброваны**. Не хватает трёх замеров на самом эндпоинте
(раздел 6.2 плана `.omo/plans/M5-mutation-gate-and-runtime.md`):

1. фактический `max_output` — пробник с длинным выводом, точка обрезания и `stop_reason`;
2. overhead пустой сессии с нашим toolset — аналог P2, но на xl; старые 2 426 не
   переносить;
3. `peak` и wall на одном реальном пакете.

До этих замеров `output` в строке xl — прочерк, а не ноль: отсутствие данных есть
отдельное состояние.

Вывод: planner-порог 128k выполняется для всех трёх planner-моделей. OMO-надбавка
(строки C/D/E) для space-bunny не переизмерялась — при замене planner-модели
переизмерить, а не переносить числа big-pickle.

## Решения
- Worker: конфиг B. Лимит qwen 46 112, свободно 36 697.
- Worker (xl): отдельная модель `qwen3.6-unlim-xl-noreason`, общий лимит 138 336.
  Калибровка обязательна до первого прогона — см. три пункта выше. На xl конфиг B
  переизмеряется, а не переносится: дельты A–E измерены на 46k-модели.
- `MAX_PEAK_CONTEXT` в `scripts/worker/dispatch.conf` — ниже провайдерского потолка минус
  фактический `max_output` (ориентир ~125 000), иначе guard не сработает первым.
  Значение принимается только после замера `max_output`.
- OMO: недопустим для любой модели <64k окна. Только planner ≥128k.
- polyforge: autoload в worker (813 токенов).
- lsp: разрешён по требованию (~1k, замерено в E).
- grep_app: DEFERRED — стоимость не измерена (сеть недоступна на момент замера).
- Связь planner↔worker: только через .sisyphus/plans/<id>/packet-NN.md.

## Инварианты packet (следуют из бюджета)
- ≤3 файла, ≤200 строк diff
- вывод тестов через output shaping >2k
- packet ≤4k токенов
